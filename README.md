# Restaurant Customer Page (demo)

Customer-facing table menu: welcome (name, mobile, DOB) -> preference popup -> 150-dish menu
(South / North Indian, veg / non-veg / kids) -> order to waiter. Support button on every page.

- Static site (no build step). Backend: Supabase (Postgres + REST, row-level security).
- Orders only - no payments.
- Only the public (publishable) Supabase key is used in the browser.
